VIT Bhopal Sports Facilities

A full-stack booking and access system for the campus pickleball, tennis and turf facilities, used by 1,000+ students. Slot uniqueness is enforced at the database level, so a double booking cannot happen.

  • Conflict-free booking: PostgreSQL constraints guarantee each slot is booked once

  • Automated lifecycle: guard-verified QR check-in, waitlist promotion and no-show tracking
  • Admin dashboard: maintenance block-outs, incident photo reports, feedback triage and usage analytics
  • Tested: constraints and RLS checked with Vitest on in-memory PGlite

CartSense Explainable Recommendations

A full-stack video game store with a built-in machine-learning recommendation engine, trained on 814,533 real Amazon reviews. Every recommendation answers "Why this?", and every one the store shows is logged, so each model version can be compared by real click-through.

  • Two-stage hybrid recommender: ALS, item-kNN, TF-IDF and popularity retrieve candidates, then an XGBoost LambdaMART ranker reorders them using 24 features
  • +39% NDCG@10 over the best single model on a held-out future time period, with leakage-free, time-based evaluation tracked in MLflow
  • Explainable: each pick carries structured reasons, such as "similar to a game you viewed" or "people who reviewed X also reviewed this"
  • Cold start handled: guests see what's trending, and a new user gets personal picks after viewing a single product
  • Production-style serving: versioned FastAPI (/api/v1) with precomputed recommendations, click logging and CTR per model version on an analytics dashboard

MeriYatra Live Transit Tracking

A real-time public-transit platform that connects daily commuters with local transport such as autos, cabs and private buses. Passengers see where their ride is right now and when it will arrive.

  • Live positions: vehicle locations stream over WebSockets (Supabase Realtime) in under 100 ms
  • Smart ETAs: an OSRM routing engine recalculates the arrival time on every GPS update
  • Two dashboards: drivers and passengers each get their own view, with ride scheduling, route search and authentication
  • Bilingual: the whole interface works in English and Hindi
  • Ships everywhere: deployed on Vercel and packaged as a Chrome extension
